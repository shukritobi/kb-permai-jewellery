# KB Permai Silvercraft & Jewellery

Concept website for KB Permai Silvercraft & Jewellery, Kota Bharu, Kelantan.

## Live site

GitHub Pages deploys automatically from `main` using the workflow in `.github/workflows/deploy-pages.yml`.

## Website highlights

- Heritage-focused landing page
- Sterling silver 925 collection showcase
- Custom order, repair and restoration enquiries
- WhatsApp-first conversion flow
- Responsive mobile layout
- KB Permai heritage timeline
- Kota Bharu contact and location section

This repository is a website concept preview and should be updated with confirmed product catalogue, pricing and official business information before production use.
